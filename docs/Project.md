# CreateYourOwnAlphabet.com
## Objetivo.
Projeto **CreateYourOwnAlphabet.com** é uma ferramenta para usuários criar Alfabetos / Fontes próprias. Utilizando as ferramentas disponibilizadas pelo Website usuário será capaz de criar alfabetos simples, criar fontes, cortar as letras de alfabetos e outras funcionalidades.
Forma da criação do Alfabeto / Fonte, é por meio de desenho, utilizando um elemento de Canvas para realizar traços que serão salvados pelo Website em uma imagem **png**.

## Requisitos.
### Funcionais.
Página Principal:
- Banner.
- Adsense.
- Botão de "Criar Alfabeto".
- Botão de "Criar Fonte".
- Botão de "Editar Alfabeto".
- Botão de "Cortar Alfabeto / Fonte".
- Adsense.
- Footer.

Página "Criar Alfabeto":
- Botões de Opção para a criação do Alfabeto. Referenciado em algum Alfabeto existente (Normal, Grego, Japones...) ou Personalizado (Capaz de aumentar a quantidade de caracteres).
  - Canva de Referência. (Modo Referenciado)
  - Canva de Desenho.
  - Ferramentas de Desenho. (Pinceis e Apagador, Cor, Espessura)
  - Ferramenta de Visualização. (Modo Transparente, Modo de Grid)
  - Ferramenta de Navegação. (Próximo Caractere, Caractere Anterior) + (Personalizado: Criar Caractere, Apagar Caractere)
  - Botão de Salvamento. (Salvar Letrar, Salvar Alfabeto)

Página "Criar Fonte":
- Ainda em Desenvolvimento.

Página "Editar Alfabeto":
- Importar Arquivo do Alfabeto. (Necessita um Arquivo onde Alfabeto é em tabela com Largura ? x Altura {? * ?} e celulas com Largura ? x Altura ? )
  - Canva de Desenho.
  - Ferramentas de Desenho. (Pinceis e Apagador, Cor, Espessura)
  - Ferramenta de Visualização. (Modo Transparente, Modo de Grid)
  - Ferramenta de Navegação. (Próximo Caractere, Caractere Anterior, Criar Caractere, Apagar Caractere)
      - Botão de Salvamento. (Salvar Letrar, Salvar Alfabeto)

Página "Corta Alfabeto / Fonte":
- Importar Arquivo do Alfabeto. (Necessita um Arquivo onde Alfabeto é em tabela com Largura ? x Altura {? * ?} e celulas com Largura ? x Altura ? )
- Botão de Cortar.
   - Usuário receberá um Arquivo Zip com **PNG** de cada caractere do Alfabeto.
